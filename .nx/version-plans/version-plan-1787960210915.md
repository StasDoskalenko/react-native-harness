A platform package can now adjust the Metro config the harness composes, via a `metroConfigEnhancer` module it points at. The harness imports it while building the config for the selected runner and lets the platform apply its own requirements. `@react-native-harness/platform-windows` uses this for the `react-native` → `react-native-windows` redirect, the extra `resolver.platforms` entries, and React Native Windows' `InitializeCore` — the wiring `react-native start` gets from the community CLI plugin, which the harness bypasses. iOS and Android runs are unaffected.
